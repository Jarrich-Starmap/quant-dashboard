3技术指标算法

每个指标输出值域为 [-1, 1]，正值偏多、负值偏空、零附近为中性。初始等权 0.25，后续由 EWMA 动态调节。

3.1 RSI — 相对强弱指数（ADX 自适应映射）

RSI 信号阈值由 ADX 趋势强度动态调制，区分趋势市与震荡市：

市场状态ADX超买阈值超卖阈值过渡区
强趋势≥ 25802070~80 / 20~30
过渡20 ~ 2570→8030→20线性插值
震荡≤ 20703060~70 / 30~40
t = clamp((ADX − 20) / 5, 0, 1)
OBthresh = 70 + 10t  |  OBtrans = 60 + 10t
OSthresh = 30 − 10t  |  OStrans = 40 − 10t

signalRSI = −1 (RSI ≥ OBthresh)  |  +1 (RSI ≤ OSthresh)
           = 线性映射 (过渡区内)  |  0 (中性区)

强趋势市场中 RSI 可长期维持 60-80，固定 70/30 阈值会导致过早反向做空。ADX ≥ 25 时阈值放宽至 80/20，仅在真正极端时发信号；震荡市保持灵敏。ADX 不参与 softmax 加权，仅作为 RSI 的调制器。

3.2 MACD — 异同移动平均线

基础信号为 离散动量确认：比较当前 hist 与前一根 hist 的变化趋势：

raw = +1 (hist > 0 且递增)  |  −1 (hist < 0 且递减)  |  0 (其他)
factor = clamp(0.7 + 0.3 × sign(MACD_Line) × raw, 0.4, 1.0)
signalMACD = raw × factor

离散信号 + 动量确认跨品种鲁棒，不受价格量级影响。零轴非对称因子使零轴上方多头信号被加强、空头信号被削弱，零轴下方对称处理。

3.3 布林带 — Bollinger Bands

基础信号：价格触及上轨 → 看空，触及下轨 → 看多。带宽乘数调节：

multiplier = clamp(1.0 + 0.3 × (1 − min(带宽比, 2)), 0.5, 1.5)
signalBB = (mid − close) / (upper − lower) × multiplier × 2
带宽状态乘数物理含义
带宽比 → 0（极度收缩）1.3突破信号加强
带宽比 = 1（正常）1.0标准信号
带宽比 ≥ 2（极度扩张）0.7回归信号加强

3.4 动量指标 — Momentum

raw = (closet − closet−n) / closet−n
accel = sign(momt − momt−1) （加速方向）
signalMOM = clamp(tanh(raw × 50) × weight, −1, 1)
动量方向加速状态权重
正向加速1.0（满分）
正向减速0.5（折半）
负向加速1.0
负向减速0.5

3.5 ADX — 趋势强度指标（RSI 调制器）

ADX（Average Directional Index）衡量趋势强度，不指示方向。作为 RSI 的调制器，不直接参与 softmax 加权。

TR = max(H−L, |H−Cprev|, |L−Cprev|)
+DM = (H−Hprev) if > (Lprev−L) and > 0, else 0
−DM = (Lprev−L) if > (H−Hprev) and > 0, else 0
+DI = 100 × WilderSmooth(+DM) / WilderSmooth(TR)
−DI = 100 × WilderSmooth(−DM) / WilderSmooth(TR)
DX = 100 × |+DI − −DI| / (+DI + −DI)
ADX = WilderSmooth(DX)
ADX 值市场状态RSI 阈值设计意图
≥ 25强趋势80/20避免趋势中过早反转
20 ~ 25过渡插值平滑切换，无跳变
≤ 20震荡70/30保持均值回归灵敏

Wilder 平滑使用 EWM(α=1/period)，与 RSI 的指数加权一致。ADX 值存入 signal_snapshots 供 Dashboard 展示。

3.6 波动率估计器 — Yang-Zhang (YZ)

方案 B' 只保留 Yang-Zhang 单一估计器，弃用 ATR/Parkinson/GK 融合与自适应加权。YZ 是 ATR 信息的严格超集：它同时分离隔夜跳空（open-to-open）与日内区间（close-to-close + Rogers-Satchell），对带夜盘、频繁跳空的期货更稳健。计算复杂度 O(n)，与单次 ATR 相当。

σ²YZ = σ²overnight + k · σ²close + (1 − k) · σ²RS
k = 0.34 / (1.34 + (n + 1) / (n − 1))

σ²overnight = Var( log(opent / closet−1) )
σ²RS = mean( log(H/O)·(log(H/O) − log(C/O)) + log(L/O)·(log(L/O) − log(C/O)) )
σ²close = Var( log(closet / closet−1) )

输出：价格分数（无量纲）σYZ = √(σ²YZ)
组件含义ATR 是否覆盖
σ²overnight隔夜跳空方差（夜盘 / 跳空）否 — ATR 完全丢失此项
σ²RSRogers-Satchell 日内区间方差（H−L）部分（ATR 用 TR 近似）
σ²close收盘−收盘方差（含方向信息）否 — ATR 不区分方向

状态评估改用 z-score（EWMA 均值 / 标准差），替代原方案的百分位排序：

yz_mean = EWMA(σYZ, span = state_window)
yz_std  = EWMA_std(σYZ, span = state_window)
z_score = (σYZ,t − yz_mean) / yz_std

z-score 与系统既有的 EWMA 衰减体系一致（O(n)），直接衡量当前波动率相对近期基线的偏离。扩展速率以快 / 慢 EMA 差值衡量：expansion_rate = (yz_fast − yz_slow) / yz_slow（fast = trend_fast = 3，slow = trend_slow = 10）。状态字符串（CALM / HIGH / EXTREME）仅用于日志与 DB，下游一律使用连续 z_score，禁止用状态做 if-elif 分支。

ATR 保留为工具量：止损层需要价格单位的绝对距离（如「18.5 点」），而 YZ 输出无量纲分数。ATR 仅用于提供价格单位，不进入估计器或融合权重。温启动保护：EWMA 未收敛时 z_score 填 0（中性），避免 NaN / 极端值。各品种参数如下：

3.7 波动率方向信号 — Expansion / Reversal

波动率作为第三路信号源，输出 vol_score ∈ [−1, 1]（理论值域；实际幅度受强度系数限制：AU/AG 上限 ≈ 0.30、SC/IC/IM 上限 ≈ 0.45，多数时段数值较小）。方案 B' 仅保留两种模式（删去 Squeeze —— BB 带宽已覆盖「压缩 → 突破」逻辑，AVI 不重复）：

模式触发方向基础置信度
Expansion follow
扩张跟随		expansion_rate 超阈值（连续 sigmoid）跟随价格趋势0.20 + 量能加成（最多 +0.10）
Extreme reversal
极端反转		z_score > reversal_z（默认 2.0）与价格趋势反向（fade）0.25（AU/AG）/ 0.45（SC）
Normal
常态		其余情况无明确观点≈ 0（让位给 tech / sent）
  • 扩张跟随：波动率快速扩张通常意味着动能正在积聚，方向取价格趋势（价格相对 EMA 的 tanh，按 ATR 缩放）。成交量确认（volume_confirm_ratio，AU/AG=1.3、SC=1.5）可额外提升置信度约 0.10。
  • 极端反转：波动率处于极端高位往往是恐慌 / 冲顶，价格更可能均值回归，方向与价格趋势相反。
  • 两种模式可重叠并平滑混合，全部用连续 sigmoid 过渡，无 if-elif 悬崖。死区 dead_zone = 0.05 过滤极小信号。

为何删 Squeeze：BB 带宽比已做「低波动 → 突破信号增强」，AVI 再做 Squeeze 是信号重叠而非信息增益。Reversal 才是 AVI 的独特 alpha —— BB 说「波动低」，AVI 说「波动极端 → 反转」，二者互补。

4信号融合机制

4.1 技术得分合成

四个技术指标通过 softmax(min-shift, τ=0.5) 动态加权：

shiftedi = ewmai − min(ewma) + ε
wi = softmax(shifted, temperature=0.5)
tech_score = Σ wi × signali   ∈ [−1, 1]

min-shift 保证所有输入非负，temperature=0.5 使权重分化更明显（优于标准 softmax），加速向优指标滑移。初始 EWMA 全为零时，shifted 全等，softmax 自动退化为均匀 0.25 权重，无需手动冷启动。

4.2 情绪得分

sentiment_score = (bullish − bearish) / (bullish + bearish)   ∈ [−1, 1]

从本地 JSON 文件读取各品种的多空情绪计数。情绪数据超过 4 小时视为过期：sentiment_score = 0，ewma_sent 冻结不更新，α 强制为 1（纯技术驱动）。

4.3 α 动态融合权重（核心算法）

技术得分与情绪得分的融合比例由 α 在线自动调节：

α = sigmoid(ewma_tech − ewma_sent)
final_score = α × tech_score + (1 − α) × sentiment_score
α 范围含义行为
α > 0.5技术指标 EWMA 胜率更高更多依赖技术信号
α < 0.5情绪分析 EWMA 胜率更高更多依赖情绪信号
α ≈ 0.5两者表现相当均衡融合

初始值差异：AU / AG 的 base_alpha = 0.5（均衡起步）；SC 原油因情绪数据可靠性较低，base_alpha = 0.4（初始略偏向情绪侧，待 EWMA 学习后自动滑移）。α 在线更新时 clamp 至 [0.2, 0.8]，防止任一侧权重极端化。

方向判定：final_score > 0 → LONG，final_score < 0 → SHORT，|final_score| < 阈值 → NEUTRAL（不交易）。

4.4 波动率三路融合（波动率开启时）

当波动率模块开启且 |vol_score| ≥ vol_epsilon 时，compute_score 由二路 α 融合升级为三路 softmax 融合：

w = softmax( [ewma_tech, ewma_sent, ewma_vol], τ )
final_score = wtech × tech_score + wsent × sentiment_score + wvol × vol_score
情形权重来源行为
波动率关闭α = sigmoid(ewma_tech − ewma_sent)与旧版逐位一致（二路 α 融合）
开启但 vol_score ≈ 0α 二路融合与旧版逐位一致（平静市自动让位）
开启且 vol_score 活跃softmax 三路波动率作为第三路信号参与融合

配置门控与逐位回退：所有集成点由 config.yaml 各品种的 volatility.enabled 开关控制。vol_score ≈ 0（平静市）时 compute_score 直接走原始 α 路径，输出与关闭波动率逐位相同 —— 即便开启模块也不会覆盖既有行为。EWMA 更新独立于 fuse()，投影法 clip 修复了早前的循环 bug。

5.1 波动率仓位乘数（连续 sigmoid）

基础仓位公式不变，额外乘以波动率仓位乘数（由 z-score 连续映射，无阈值跳变）：

position_size = base_lot × |final_score| × risk_multiplier × vol_multiplier

vol_multiplier = clamp( 1.20 − 0.87 · sigmoid(z), 0.25, 1.30 )
s = sigmoid(z, center=0, steepness=1.5)
扩张惩罚：expansion_rate > 0.10 → 额外 ×0.85（连续 sigmoid）
z_score−2（平静）0（正常）+1（偏高）+2（极端）
vol_multiplier1.201.00≈0.50≈0.33

波动越低，仓位可略放大（最多 1.20×）；波动越高，仓位连续收缩（极端 ≈0.33×，最低 0.25×）。波动率快速扩张时再叠加减仓，避免追高波动。

6EWMA 在线学习

6.1 盈亏映射 — Reward 函数

risk_capital = entry_price × contract_multiplier × position_size
reward = tanh(pnl / (risk_capital × risk_per_trade))

使用 tanh 平滑映射替代二元胜负，避免单笔极端盈亏主导 EWMA 更新。risk_per_trade 使 reward 对盈亏百分比更敏感（2% 盈利 → tanh(1.0) ≈ 0.76），加速 EWMA 学习。

6.2 EWMA 更新规则

ewmanew = β × ewmaold + (1 − β) × reward
β = 0.9  （半衰期 ≈ ln(0.5) / ln(0.9) ≈ 6.5 周期）

6.3 技术/情绪 EWMA 独立更新

技术侧和情绪侧的 EWMA 各自独立评估，不与综合交易结果混为一谈：

EWMA 流判断依据reward
ewma_techsign(tech_score) 是否等于实际涨跌方向方向一致 +1，方向相反 −1
ewma_sentsign(sentiment_score) 是否等于实际涨跌方向方向一致 +1，方向相反 −1
ewma_volsign(vol_score) 是否等于实际涨跌方向方向一致 +1，方向相反 −1（与 tech/sent 完全独立）

这一解耦使 α = sigmoid(ewma_tech − ewma_sent) 能真正滑向更可靠的一侧——技术总能预测对而情绪屡次错时，α 自然向 1 偏移；反之向 0 偏移。

6.4 跳过更新的场景

场景指标 EWMA (rsi/macd/bb/mom)技术/情绪 EWMA (tech/sent)
未开仓周期（NEUTRAL / 冷却 / 数据过期）正常更新（基于价格涨跌）不更新（无交易结果）

6.5 指标 EWMA 动态更新

每个周期（warmup 结束后）对比上一周期各指标信号方向 sign(signali) 与实际价格涨跌方向：

  • 方向一致 → ewmai = β × ewmai + (1 − β) × (+1)
  • 方向相反 → ewmai = β × ewmai + (1 − β) × (−1)

指标 EWMA 每周期更新，不依赖是否开仓——即使方向为 NEUTRAL 或处于冷却期，只要价格有涨跌就会更新。此机制使 softmax 权重自动向近期表现更好的指标滑移，劣化指标的权重自然衰减。仅在价格无变化（actual_dir = 0）或首周期（无 prev_price）时跳过。

6.6 波动率 EWMA 与 reward 加权

ewma_vol 与技术 / 情绪 EWMA 完全独立更新，机制相同（方向一致 +1 / 相反 −1），仅初始值不同（默认 0.5）。它专用于驱动 三路 softmax 融合 中波动率一路的权重滑移。

当开启 volatility.adjust_reward 时，PnL 类 reward 会按波动率难度加权（仅缩放 tanh 映射的 reward，不触碰方向 ±1 的 EWMA）：

weight = clamp( 0.85 + 0.65 · sigmoid(z, center=0, steepness=1.0), 0.80, 1.50 )
rewardadj = reward × weight
z_score−1（低波动）0（正常）+1（偏高）+2（极端）
reward 权重0.85（盈利较易，略折减）1.001.30（盈利较难，放大）1.50（最大放大）

方向 ±1 的 EWMA 学习机制是「神圣不可动」的；adjust_reward 只调整 PnL reward 的难度因子，不改变方向评估。当前生产配置 adjust_reward = false，尚未启用。

7.2 数据源解耦

Adapter 层将 AkShare 中文列名映射为标准 OHLCV，支持更换数据源时只改 adapter。同时负责主力合约解析（resolve_contract_code）。

主力合约解析流程：SHFE/INE 合约信息接口获取合约列表 → 筛选已上市且未到期的合约 → 取最近到期的 4 个候选 → 逐一查询 futures_zh_daily_sina 日K线 → 比较持仓量（hold），选最大者 → 结果缓存 1 小时。非交易日查询自动往前回溯最多 3 天。

7.3 三级止损机制

每笔持仓在每轮信号计算前检查止损条件，优先级从高到低：

层级触发条件行为
硬止损 HARD_STOP浮亏 ≥ hard_stop_loss（全部品种 6%）立即市价平仓，不等待信号方向
保本止损 BREAKEVEN浮盈曾达到 breakeven_trigger 后回落至入场价以入场价平仓，锁定零亏损
移动止损 TRAILING从持仓期间峰值回撤 ≥ trailing_stop_pct（AU/AG/IC/IM 2%, SC 3%）市价平仓，保护已有利润

硬止损无条件执行；保本和移动止损仅在浮盈突破触发阈值后才激活。peak_price 追踪持仓期间最佳价格，每次信号计算前更新。

LONG: loss_pct = (entry − price) / entry
SHORT: loss_pct = (price − entry) / entry
止盈则用 profit_pct 对称计算。

7.4 手续费与滑点

模拟成交自动扣除双边手续费并施加不利方向滑点：

品种手续费模式费率滑点率
AU固定10 元/手0.02%
AG比例合约值 × 0.005%0.03%
SC固定20 元/手0.04%
IC比例万分之 0.230.02%

滑点方向始终对交易者不利：做多时成交价上浮、做空时下浮。vol_penalty 由波动率 z-score 连续映射（替代原离散的「ATR/价格 > 2%」判定），高波动时滑点放大、低波动时收窄，与信号层共享同一波动率评估。

LONG: fill_price = price × (1 + slippage_rate × vol_penalty)
SHORT: fill_price = price × (1 − slippage_rate × vol_penalty)

7.6 期末强制平仓

每交易时段最后一分钟自动触发强制平仓，防止隔夜跳空风险。判断逻辑：下一分钟不在任何交易时段内时触发（10:15、11:30、15:00、02:30）。夜盘 21:00–23:59 与 00:00–02:30 为连续交易时段，23:59 不触发平仓。

is_session_end_cycle(now) = is_trading_time(now) ∧ ¬ is_trading_time(now + 1min)

触发时调用 trader.force_close() 对所有持仓标的强制平仓，记录 PnL 和 signal_snapshot 后本周期提前返回，不再执行信号计算和开仓逻辑。

7.7 波动率连续风控（统一惩罚）

波动率风控层将所有惩罚统一为 z_score 的连续 sigmoid 映射，完全消除阈值跳变（cliff-effect）。仓位、滑点、止损三路共享同一 z_score → 连续映射，保证信号层与执行层始终同步：

s = sigmoid(z, center=0, steepness=1.5)
vol_multiplier  = clamp(1.20 − 0.87 · s, 0.25, 1.30)
slippage_factor = clamp(0.80 + 1.20 · s, 0.70, 2.50)
stop_multiple   = clamp(1.50 + 1.50 · s, 1.0, 4.0)
z_score−20+1+2
vol_multiplier1.201.000.500.33
slippage_factor0.801.001.502.00
stop_multiple（ATR 倍数）1.52.02.53.0

动态止损以 ATR × z-score 自适应倍数计算（volatility.dynamic_stop 开启时替换原固定百分比止损），并受硬止损上限与 0.5×ATR 下限约束：

atr_multiple = 1.50 + 1.50 · s
stop_distance = clamp( ATR × atr_multiple, 0.5 × ATR, entry × hard_stop_pct )
z > 2.5 → pause_new_entry（极端波动暂停新开仓）

当前生产配置中 AU 已开启 dynamic_stop 与 adjust_reward（P2 止损 / P3 三路融合已灰度生效）；其余品种仍为 false，波动率模块处于影子 / 静默模式：市场平静时 vol_score ≈ 0，系统行为与旧版完全一致。此为方案 B' 的渐进式上线策略（P1 影子 → P2 止损 → P3 三路融合 → P4 全量）。
